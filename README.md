# Kalma: il mio gruppo di agenti IA

Progetto per imparare a costruire agenti IA che si dividono i compiti.

- `agenti/`: il codice Python degli agenti
- `vault/`: la cartella di note (apribile con Obsidian), memoria condivisa degli agenti

## Tappa 0
1. `pip install -r requirements.txt`
2. Imposta la chiave: `export ANTHROPIC_API_KEY="la-tua-chiave"`
3. `python3 agenti/ciao.py`
